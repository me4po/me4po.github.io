## 为什么是终端的样子

一开始只是想找个地方写东西。看过太多默认样式的博客之后，我确认了一件事：**写东西的地方应该长得像能折腾东西的地方**。

于是有了这个站点：深空黑底、等宽字体、荧光绿的高亮，标题一个字一个字地打出来。它不是复古癖，是一种态度声明——内容是手写的，不是套模板生成的。

## 它是怎么跑起来的

整条链路比想象中短：

```text
本地编辑器 / 浏览器（github.dev）里写 Markdown
    → push 到 GitHub
        → GitHub Actions 云端构建
            → GitHub Pages → 你正在看的这个页面
```

正式构建在云端完成，本地不需要装 Hugo；换一台电脑，用浏览器打开 github.dev 就能继续写。
